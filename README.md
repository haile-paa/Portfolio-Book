# Haileyesus Eyasu — Portfolio
React + TypeScript + Vite, Tailwind CSS v4, Three.js, Framer Motion.

    npm install
    npm run dev      # local dev server
    npm run build    # production build in dist/ (deploy to Vercel as-is)

Edit contact details, projects and stack in `src/data.ts`. The chat widget answers from `getReply` in `src/components/Chat.tsx`; replace it with a call to your own API to make it live.
